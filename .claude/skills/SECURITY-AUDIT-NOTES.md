# security-audit skill

Copied unchanged from Cloudflare's official github.com/cloudflare/security-audit-skill
(commit c1c8a8c, MIT licence in `CLOUDFLARE-LICENSE`). Ask "security audit this project" for the full
audit; smaller security questions use guidance mode.

Write reports to `.security-audit/run-<N>/` in this repo (git-ignored, so findings never reach GitHub).
The default `~/security-audit-skill/...` is lost when a cloud session ends.
